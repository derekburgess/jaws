# CLI reference

Generated by `python scripts/generate_reference.py` from the 3.0 entry-point inventory and each parser's `--help` output. `jaws-guide` is narrative guidance and is intentionally represented by the workflow documentation rather than a parser snapshot.

## `jaws-admin`

```text
usage: jaws-admin [-h] --database DATABASE [--confirm CONFIRM] [--limit LIMIT]
                  {plan,erase,audit}

Plan, explicitly confirm, and audit destructive operations. This interface is
intentionally not agent-accessible.

positional arguments:
  {plan,erase,audit}

options:
  -h, --help           show this help message and exit
  --database DATABASE  Exact Neo4j database name; destructive operations have
                       no default target.
  --confirm CONFIRM    For erase, the exact confirmation string emitted by a
                       current plan.
  --limit LIMIT        Audit records to return.
```

## `jaws-compute`

```text
usage: jaws_compute.py [-h] [--api {openai,transformers,numeric}]
                       [--model {jina-code,securebert}] [--database DATABASE]
                       [--session SESSION] [--retain-profiles RETAIN_PROFILES]

Compute per-IP endpoint embeddings using either OpenAI or Transformers.

options:
  -h, --help            show this help message and exit
  --api {openai,transformers,numeric}
                        Representation provider: 'openai', 'transformers', or
                        'numeric' for no embedding provider (default:
                        'openai').
  --model {jina-code,securebert}
                        Local transformers model to use when --api
                        transformers (default: 'jina-code'). Add more in
                        config.PACKET_MODELS.
  --database DATABASE   Specify the database to connect to (default:
                        'captures').
  --session SESSION     Which capture session to profile: 'latest' (default),
                        'all' (every packet in the graph; timing still never
                        crosses session boundaries), or a specific CAPTURE_ID
                        from a capture run.
  --retain-profiles RETAIN_PROFILES
                        How many computed profile sets (sessions) to keep in
                        the graph; older ones are pruned after this run
                        (default: 20). Profiles accumulate per session so
                        jaws-finder can baseline an endpoint against its own
                        history. 0 disables pruning. Raw PACKET/CAPTURE
                        history is never pruned.
```

## `jaws-finder`

```text
usage: jaws_finder.py [-h] [--database DATABASE] [--components COMPONENTS]
                      [--whiten] [--eps EPS] [--feature-weight FEATURE_WEIGHT]
                      [--include-local] [--session SESSION] [--no-baseline]
                      [--ablate]

Perform DBSCAN clustering on embeddings fetched from the database.

options:
  -h, --help            show this help message and exit
  --database DATABASE   Specify the database to connect to (default:
                        'captures').
  --components COMPONENTS
                        Number of PCA components to retain for clustering. The
                        first 2 are always used for plotting, so values below
                        2 are clamped (default: 2).
  --whiten              Whiten the PCA components (scale each to unit
                        variance). Improves geometry with few strong
                        components, but amplifies noise when retaining many
                        low-variance components (default: off).
  --eps EPS             DBSCAN epsilon. When omitted, it is auto-recommended
                        from the k-distance knee. The knee tends to overshoot
                        on small/homogeneous datasets (folding everything into
                        one cluster, 0 outliers) — pass a smaller value to
                        surface more outliers.
  --feature-weight FEATURE_WEIGHT
                        Influence of the behavioral numeric features
                        (bytes/packets/peers, in & out) on clustering. The
                        numeric block is standardized to unit variance and
                        scaled by this weight; the text embedding keeps its
                        natural scale. 0 = embedding-only (text/org/protocol
                        structure), higher = more volume/fan-out influence to
                        surface behavioral anomalies. Default 1.0.
  --include-local       Include the capture host ('YOU ARE HERE') in the
                        clustered set. Off by default — it is a structural hub
                        that dominates clustering. Its outbound traffic still
                        appears as each remote endpoint's inbound, so outbound
                        anomalies are detectable without it.
  --session SESSION     Which stored profile set to analyze: 'latest' (default
                        — the most recently computed), or a specific
                        CAPTURE_ID that jaws-compute has profiled. Profile
                        sets accumulate one per capture session.
  --no-baseline         Disable historical baselining and score every endpoint
                        purely against its current peers. By default, an
                        endpoint with at least 2 prior profiled sessions is
                        measured against its OWN history (volume and shape
                        features only — cadence stays peer-relative so a
                        persistent beacon can't normalize itself), which stops
                        endpoints that are always heavy from dominating the
                        ranking every run.
  --ablate              Ablation mode: cluster the same endpoints three ways —
                        text-only (embedding alone), numeric-only (behavioral
                        features alone), and blended — and report cluster
                        quality (silhouette) and outlier-set agreement
                        (Jaccard) to quantify how much the embedding
                        contributes. Reuses stored embeddings, writes nothing,
                        generates no plots.
```

## `jaws-ipinfo`

```text
usage: jaws_ipinfo.py [-h] [--database DATABASE] [--max-attempts MAX_ATTEMPTS]
                      [--request-interval REQUEST_INTERVAL]
                      [--initial-backoff INITIAL_BACKOFF]
                      [--backoff-multiplier BACKOFF_MULTIPLIER]
                      [--max-backoff MAX_BACKOFF]

Update the database with IP organization information from Ipinfo.

options:
  -h, --help            show this help message and exit
  --database DATABASE   Specify the database to connect to (default:
                        'captures').
  --max-attempts MAX_ATTEMPTS
                        Maximum provider attempts per public address.
  --request-interval REQUEST_INTERVAL
                        Minimum seconds between provider requests.
  --initial-backoff INITIAL_BACKOFF
                        Seconds to wait before the first transient retry.
  --backoff-multiplier BACKOFF_MULTIPLIER
                        Multiplier applied to each subsequent retry delay.
  --max-backoff MAX_BACKOFF
                        Maximum seconds for any transient retry delay.
```

## `jaws-research`

```text
usage: jaws-research [-h]
                     {validate,run,status,cancel,inspect,compare,verify,components,operation,export,import}
                     ...

positional arguments:
  {validate,run,status,cancel,inspect,compare,verify,components,operation,export,import}
    validate            validate an immutable experiment spec
    run                 execute the declared control/treatment matrix
    status              read an atomic run lifecycle snapshot
    cancel              request cooperative run cancellation
    inspect             inspect a run bundle without Neo4j
    compare             compare analytical run artifacts
    verify              verify every bundle checksum
    components          list available versioned components
    operation           run one deterministic operation outside a formal
                        experiment
    export              export a portable bundle without raw PCAP
    import              import and verify a portable bundle

options:
  -h, --help            show this help message and exit
```
